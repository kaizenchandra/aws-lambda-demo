# ADR-011 — SDK retries bounded; queue owns business retry

## Context

Retry loops across every layer amplify outages and can exceed Lambda deadlines.

## Decision

Two SDK attempts within four seconds; no application retry loop; SQS redrive and scheduled outbox retries. Relay aliases disable Lambda asynchronous retries to prevent overlapping retry layers; durable outbox state survives dropped wakeups.

## Alternatives Considered

Unbounded retries; immediate custom retry loops; acknowledgement on failure.

## Consequences

Bounded call duration; prolonged outages become backlog/DLQ signals. Deadlines still require load testing and timeout headroom.
