# ADR-008 — Pinned LocalStack and same Terraform topology

## Context

Local tests must cover service interactions without an AWS account.

## Decision

Pinned LocalStack 4.12.0 and Terraform AWS 6.0.0; Testcontainers for adapter tests; Compose+Terraform for Lambda E2E.

## Alternatives Considered

Mock every SDK call; use shared AWS dev account for every test.

## Consequences

Deterministic fast feedback, but IAM/KMS/X-Ray/SLO verification still requires AWS staging. Provider/emulator upgrades are paired; see design decision-change log.
