# ADR-007 — Typed versioned integration envelopes

## Context

Services evolve and need business correlation across asynchronous boundaries.

## Decision

Typed JSON envelope v1.0, deterministic logical event IDs, correlation/causation metadata, additive-field compatibility, strict required-field/version validation.

## Alternatives Considered

Java serialization; sharing aggregates; unversioned arbitrary maps.

## Consequences

Language-neutral contract and consumer tests; breaking changes require dual-version rollout. Domain events remain internal.
