# ADR-002 — SQS buffers and SNS distributes integration events

## Context

Fulfillment must not reduce ordering availability; downstream consumers may grow.

## Decision

Outbox → SNS topic → raw SQS subscription → Lambda; separate processing and SNS delivery DLQs.

## Alternatives Considered

Direct Lambda invocation; only SQS; EventBridge routing bus.

## Consequences

Durable backpressure and independent subscribers; more resources and at-least-once delivery. EventBridge is used only for relay scheduling.
