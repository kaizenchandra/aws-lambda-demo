# ADR-003 — Access-pattern-first DynamoDB

## Context

Lookup by order ID, conditional transitions and durable pending publication are primary access patterns.

## Decision

One table per context, PK aggregate/outbox keys, sparse four-shard pending GSI, transactions and strong conflict-resolution reads.

## Alternatives Considered

Relational database with joins; shared single table; scans.

## Consequences

Independent ownership and serverless capacity; denormalized payloads and explicit GSI/replay operations.
