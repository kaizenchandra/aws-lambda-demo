# ADR-006 — Transactional outbox and aggregate inbox

## Context

A database write followed by network publication can lose events; messages and concurrent workers can duplicate.

## Decision

Aggregate+outbox transaction; publish-before-mark; durable pending fulfillment stores source event and digest; version-checked completion+outbox.

## Alternatives Considered

Unsafe dual write; volatile dedupe; global transactions; FIFO as a substitute for idempotency.

## Consequences

No lost committed outgoing intent; duplicates remain possible; durable retention and reconciliation are operational duties.
