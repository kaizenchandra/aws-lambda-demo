# ADR-010 — IAM authentication for B2B API

## Context

Contracted clients can sign AWS requests; customer ownership must not come from body fields.

## Decision

API Gateway AWS_IAM, owner checks using authenticated userArn, local bypass only in local environment.

## Alternatives Considered

Anonymous API; API keys as authentication; JWT authorizer.

## Consequences

Least-privilege B2B access; stable principal/session naming required. A consumer SaaS should introduce stable JWT subjects and explicit owner migration.
