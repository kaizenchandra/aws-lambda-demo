# ADR-005 — Core modules enforce inward dependencies

## Context

Domain rules must run without AWS or Spring; context vocabulary must remain separate.

## Decision

Framework-free contracts, ordering-core, fulfillment-core; runtime adapters depend on cores. Explicit ports and constructor injection.

## Alternatives Considered

One package-by-layer monolith; domain entities annotated for persistence.

## Consequences

Fast pure unit tests and replaceable runtime; some explicit mapping and deployment packaging code.
