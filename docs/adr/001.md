# ADR-001 — Managed Lambda and direct Java handlers

## Context

Bursty acceptance and bounded asynchronous processing need isolated scaling.

## Decision

Managed java21 ARM64 ZIP, AWS RequestHandler, one reused non-web Spring Boot context per execution environment.

## Alternatives Considered

Spring Cloud Function, custom bootstrap, Lambda image, always-on ECS.

## Consequences

Explicit AWS event boundaries and simple deployment; cold-start latency and platform timeout constraints require
measurement.
